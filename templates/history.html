Changelog

  • 2026-10-10

    We re-screened the data in the database and removed duplicate entries. After deduplication, 133,073 records remained, including 131,685 in the “other” category, 1,167 spermidine entries, and 221 spermine entries.

  • 2026-05-14

    Added 29 newly curated polyamine conjugate entries (L00600118–L00600146), corrected and standardized QED scores across all 142,376 compounds, and relaunched the web interface on a Flask-based architecture with improved performance and UI.

  • 2025-03-03

    We made optimizations in search speed and data result display. In the advanced search module, we changed the query output results to page display, which will increase the search speed. In the synthesis route search module, we added the reaction conditions of each step for reference.

  • 2025-02-18

    We added 206 polyamine molecules synthesized by our own laboratory to the database, along with their synthesis routes. At the same time, we added a new function for similar search of synthesis routes. Finally, we made some changes to the website interface.

  • 2024-12-08

    We manually re-screened the original more than 370,000 polyamine molecules and ultimately screened out 142,142 polyamine conjugates that met our new standards. The classification work is still in progress.

  • 2024-06-10

    In order to further screen possible polyamine conjugates, NCN v2.0 was developed to expand the search scope of polyamine conjugates and find more than 370,000 possible polyamine conjugate analogs.

  • 2024-03-08

    By developing a cleaning tool such as NCN v1.0, the number of polyamine conjugates initially screened was 227,389.

  • 2023-12-02

    Initially built and tested the database website.
